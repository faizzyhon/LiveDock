# Changelog

## 1.1.0
- **New liquid glass dock.** Drawn by LiveDock itself (no square box any more): lensing at the edge, light rim that follows the shape, soft shadow, tint that adapts to your wallpaper.
- **Fluid motion.** Icons grow with springs and settle with a small bounce. Names show above the icon. Press feedback on click.
- **Cleaner icons.** Real transparency for all app icons (no black corners). New glass tiles for Start and Studio.
- **Wallpaper fix for Windows 11 24H2 / 25H2.** The wallpaper window now uses the new desktop layout. It re-attaches by itself if Explorer changes. New menu item: *Fix wallpaper (reconnect)*. A small `livedock.log` shows which layout was found.
- **New LiveDock Studio look.** Segmented tabs, cleaner cards, file type badges, better spacing.
- App manifest added (Windows 10/11 compatible, DPI aware).

## 1.0.0
- First release: live wallpaper, transparent dock, Studio, video to GIF, PayPal support.
